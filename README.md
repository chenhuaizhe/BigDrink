# BigDrink

An elegant water tracking app with HealthKit integration and Apple Watch support, helping you maintain healthy hydration habits effortlessly.

## Features

- 📱 Clean and intuitive iOS interface
- ⌚️ Native Apple Watch app and complications
- 🏥 HealthKit integration for water intake tracking
- ☁️ iCloud sync across devices
- 🔔 Smart hydration reminders
- 📊 Detailed statistics and trends
- 🔄 Widget support for quick tracking
